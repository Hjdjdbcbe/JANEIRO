# نسخة الديمو

ملف HTML واحد مستقلّ من واجهة المتجر: نفس الصفحة، ونفس التنسيقات، ونفس
كود التطبيق — لكن الكتالوج وكل الصور والخطوط مخبوزة داخله، فيعمل بلا خادم
ولا قاعدة بيانات ولا اتصال. لمشاركة نسخة يضغط فيها أحدهم قبل النشر.

```bash
# يحتاج الخادم المحلي شغّالاً (bash run-locally.sh) ليقرأ منه الكتالوج
node tools/build-demo.js              # -> demo/janeiro-demo.html
node tools/build-demo.js --artifact   # بلا هيكل المستند، لمن يوفّره بنفسه
```

الملفان الناتجان مستثنيان في `.gitignore` — نحو 2.6 ميغابايت لكلٍّ منهما،
ويُبنيان في ثوانٍ.

## ما هو حقيقي فيه وما هو محاكاة

القراءة كلها تمرّ بدالة واحدة في `js/janeiro-api.js` اسمها `rest`، والكتابة
بدالة واحدة اسمها `callFn`. الديمو يستبدل هاتين فقط. كل ما عدا ذلك — العرض،
والسلة، وحساب الأسعار، والمدار، والثيم — هو الكود الذي يُنشر حرفياً.

| | |
|---|---|
| **حقيقي** | الكتالوج والأسعار والخطط وطرق الدفع والعروض، لقطة من قاعدة البيانات وقت البناء |
| **محاكاة** | إنشاء الطلب وإرساله وتتبّعه — في ذاكرة الصفحة، ورقم الطلب يبدأ بـ`JNR-DEMO` |
| **محاكاة** | رفع الوصل: يتحقّق من الحجم والصيغة كما يفعل الحقيقي تماماً، ثم يتوقّف قبل الإرسال |

الصفحة تحمل شارة ثابتة: **«معاينة — لا تُرسل طلبات فعلية»**.

المنتجات التي بلا `icon_path` تحاول جلب شعارها من `cdn.simpleicons.org` كما
في الموقع الحقيقي؛ إن تعذّر ذلك ظهر حرف الاسم — وهو نفس سلوك النسخة المنشورة.
