# ملفات bucket `product-media`

هذا المجلد **مرآة للـbucket**. ما بداخله يُرفع كما هو إلى:

`Supabase → Storage → product-media`

مع الحفاظ على نفس المسارات — لأن `poster_path` و`icon_path` في القاعدة
تشير إلى هذه المسارات بالضبط.

```
products/<slug>.png      بوستر المنتج    — نسبة 3:4 (مثلاً 1086×1448)
categories/<slug>.png    أيقونة التصنيف  — 128×128، خلفية شفافة
```

## لماذا 3:4

بطاقات المنتجات مصمَّمة عمودية: الأيقونة في الأعلى، الاسم في الشريط
الأبيض، والنطاق في الشريط الأسود. فتحة البوستر في الموقع مضبوطة على
نفس النسبة، فتظهر البطاقة كاملة. لو كانت مربّعة لقُصَّ الاسم والنطاق —
أي نصف ما صُمِّمت البطاقة لأجله.

المنتج بلا بوستر يعرض البديل المصمَّم تلقائياً. ليس عطلاً.

## بعد الرفع

```sql
update products set poster_path = 'products/<slug>.png' where slug = '<slug>';
```
