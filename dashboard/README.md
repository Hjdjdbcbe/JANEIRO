# لوحة Janeiro

**تُنشر وحدها، على نطاق منفصل — لا داخل المتجر.**

هذا المجلد تطبيق قائم بذاته: ملف واحد بلا اعتماديات ولا بناء. لا يشترك
مع المتجر في أي شيء غير قاعدة بيانات Supabase.

## لماذا منفصلة

وضعها على `janeiro.com/admin` يجعلها جزءاً من نشر المتجر: أي زائر يجرّب
العنوان يجدها، وأي خطأ في إعداد النشر يكشفها، وكل إصدار للمتجر يعيد
نشرها معه.

الأمان هنا لا يعتمد على إخفاء العنوان — `admin_update_order_status`
و`admin_dashboard_stats` تفحصان `is_admin()` في الخادم، فحتى من وجد
الصفحة لا يحصل على شيء. لكن **الفصل يقلّل السطح**: صفحة أقل على نطاقك
العام، ونشر لا يخلط أداة داخلية بواجهة زبائن.

## النشر

انشر **هذا المجلد وحده** كموقع مستقل:

| المنصّة | الإعداد |
|---|---|
| Netlify / Vercel | موقع ثانٍ من نفس المستودع، `Base directory` = `dashboard` |
| Cloudflare Pages | مشروع ثانٍ، `Build output directory` = `dashboard` |
| أي استضافة | ارفع `dashboard/` فقط |

اربطه بنطاق لا يخمّنه أحد: نطاق آخر تملكه، أو نطاق فرعي غير معلن.

**تأكد أن نشر المتجر لا يشمله.** إن كنت تنشر جذر المستودع فأنت تنشر
اللوحة معه — اجعل جذر نشر المتجر `frontend/` لا الجذر.

## المفاتيح

انسخ `config.example.js` إلى `config.js` وعبّئه:

```js
window.JANEIRO_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi...",
};
```

`config.js` في `.gitignore`. المفتاح `anon` عام بالتصميم — ما يحميك هو
RLS وفحص `is_admin()` في الخادم، لا سرّية المفتاح. **لا تضع
`service_role` هنا إطلاقاً.**

## حساب الأدمن

```sql
-- أنشئ المستخدم من Supabase → Authentication → Add user، ثم:
insert into profiles (id, role, full_name)
values ('USER-UUID-HERE', 'admin', 'اسمك')
on conflict (id) do update set role = 'admin';
```

من ليس له صفّ بدور `admin` يُرفض حتى لو سجّل الدخول بنجاح.

## ما بداخلها

**نظرة عامة** — ما يحتاجك الآن، أرقام اليوم مقارنةً بالأمس، سبعة أيام
كرسم، أكثر المنتجات مبيعاً في 30 يوماً، والإجماليات.

**الطلبات** — طابور بحسب الحالة، وتفاصيل الطلب ببيانات التفعيل وأزرار
نسخ ورابط موقّت للوصل، ونقل الحالة بالأسباب.

### كيف يُحتسب الدخل

الطلب يُحتسب دخلاً من لحظة **تأكيد الدفع**، ويخرج من الحساب إن **استُرجع**.
الطلبات بانتظار الوصل أو تحت المراجعة ليست دخلاً — ليست مالاً بعد،
وعدّها يُجمّل الرقم بلا سبب.
